# TinyBio.Link

Create a personal link-in-bio page.

## Features

- Custom profile page
- Premium plan

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/tinybio-link-hub.git
cd tinybio-link-hub
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
